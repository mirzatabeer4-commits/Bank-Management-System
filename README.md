Simple Java Banking System:

A simple console-based banking system developed in Java to demonstrate basic banking operations, object-oriented programming, exception handling, and file organization. The program allows users to deposit and withdraw money from a checking account while handling insufficient funds through a custom exception.

Features:

Deposit Money: Add funds to a checking account.
Withdraw Money: Withdraw funds if the available balance is sufficient.
Custom Exception Handling: Uses InsufficientFundsException to handle withdrawals that exceed the account balance.
Balance Management: Tracks the account balance and account number.
User Input: Uses Java's Scanner class to accept deposit and withdrawal amounts.

Technologies Used: 

Java
Object-Oriented Programming (OOP)
Custom Exception Handling
Java Scanner Class

Project Files:

BankDemo.java — Main class that runs the banking program and accepts user input.
CheckingAccount.java — Manages account details, deposits, withdrawals, and balance.
InsufficientFundsException.java — Custom exception class for handling insufficient funds.

Learning Objectives:

This project demonstrates the fundamentals of Java programming, including classes and objects, encapsulation, methods, exception handling, and basic account management.

Note: This is a beginner-friendly educational project and does not implement real banking security or persistent file storage.
